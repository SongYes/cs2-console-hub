## 一、查出的真 bug（4 个，已修）

### 0. 默认模型名已过期（真实 AI 测试查出）🔴

用真实 DeepSeek Key 实测，`/models` 返回：

```
['deepseek-flash', 'deepseek-v4-pro']
```

而应用里的预设与默认值是 `deepseek-chat` / `deepseek-reasoner` —— **一个都对不上**。

**为什么这是个 bug 而不是小事**：官方文档明确写着，旧模型名**仍可调用但不报错**，
请求会由服务端转成 Flash 提供服务。也就是说：

- 用户填 `deepseek-chat`，**不会报错**，但实际跑的是 `deepseek-flash`
- 应用「模型名写错」的检查因此**完全失效**（实测：请求 `deepseek-chat`，
  返回的 `model` 字段是 `deepseek-flash`）
- 界面还显示"模型 deepseek-chat"，**用户以为的和实际跑的不是同一个**

**修法**：
1. 新增 `DEFAULT_MODEL = 'deepseek-flash'`（放在 `const S = {` **之前**——
   `const` 有暂时性死区，放后面会直接抛 `Cannot access before initialization`）
2. 6 处默认值 + 下拉列表 + placeholder 全部更新
3. 默认输出预算 `8192 → 16384`：新模型**默认开启思考模式**，思考也占这个预算
4. 旧建议「改用 deepseek-chat 这类非推理模型」**已不成立**（flash 本身就是思考模式），
   改为「调大输出预算 / 降推理强度」
5. e2e 加**防回归断言**：默认模型必须是 `deepseek-flash`、下拉列表必须含两个当前模型、
   预算必须 ≥ 16384、placeholder 不能是已下线的名字

### 1. 损坏的 localStorage 会导致应用**启动失败** 🔴

| 场景 | 错误 |
|---|---|
| `cs2hub.ai` 存了非法 JSON | `SyntaxError: Expected property name or '}' in JSON` → 启动流程中断 |
| `cs2hub.cfg` 存了非数组（如字符串） | `TypeError: S.cfg.map is not a function` |

**严重性**：用户手动改坏存储、或写入过程中断电/退出，应用就**打不开**——而且因为是在
`safeParse` 之外，错误直接抛到顶层。

**修法**：新增带**类型校验**的安全读取函数：

```js
function readLS(key, fallback, check) {
  let v;
  try { v = JSON.parse(localStorage.getItem(key) || 'null'); }
  catch (e) { return fallback; }            // 内容损坏
  if (v == null) return fallback;
  if (check && !check(v)) return fallback;  // 类型不对
  return v;
}
```

应用到 4 个键：`cs2hub.cfg`（数组）、`cs2hub.aiZh`（对象）、`cs2hub.ai`（对象）。
同时把 `testAi()` 里「自己写进去再 JSON.parse 读出来」的往返去掉，直接用输入框的值。

### 2. 悬空 id 引用：`favBadge`

`$('#favBadge')` 被引用 2 次，但 HTML 里没有、JS 也没创建 —— 是「顶栏收藏徽标」的残留
（该功能此前已按要求删除）。有 `if (b)` 保护不会崩，但属死代码。
**已删除**（含 `_setFavBadge()` 函数与 2 个调用点）。

## 六、附带核实的两件事

### 1. 「搜索只返回 16 行」不是截断

```
搜索「雷达」 → viewTotal 16, shown 16, domRows 16
JS 手写过滤（名字或释义含「雷达」）→ 17 条
```

差 1 条是应用的近义词扩展。**16 条是真命中，没有截断。**
`cl_` 搜到 196 条、渲染 120 条是**分页**设计（pageSize=120），不是 bug。

### 2. 「滚动回跳」bug **没有复发**

用户此前反馈过「鼠标指针落在第一列卡片时下滑进度卡顿回退」。本次实测：

```
有效滚动容器 = listPane（scrollHeight 7066 vs clientHeight 787），不是 body
set scrollTop 800  → 读回 800  ✓
再渲染一批后        → 仍为 800  ✓   ← 关键：不跳回
set scrollTop 1600 → 读回 1600 ✓
```
