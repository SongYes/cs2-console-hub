## 下载哪个

| 文件 | 适合谁 | 说明 |
|---|---|---|
| `CS2ConsoleHub-1.0.0-Setup.exe` | 大多数人 | 安装程序。可选安装目录，自动创建桌面与开始菜单快捷方式，可在「设置 → 应用」卸载 |
| `CS2ConsoleHub-1.0.0-Portable.exe` | 想免安装 / 放 U 盘 | **单个 exe，双击即用**，不写注册表、不建快捷方式 |

> 安装包使用**纯 ASCII 文件名**：GitHub Releases 上传时会把中文等非 ASCII 字符
> 从附件名里剔除，用中文名会变成 `CS2.-1.0.0-Installer.exe` 这种残缺名。
> 安装后的桌面 / 开始菜单快捷方式仍是中文「CS2 控制台指令查询中心」。


两者功能完全一致，按需要选一个即可。**无需安装 Python 或任何运行时。**

> **首次运行会有 SmartScreen 提示**：本程序未做代码签名（无证书），
> Windows 可能提示「已保护你的电脑」。点「更多信息」→「仍要运行」即可。
> 校验 `SHA256SUMS.txt` 可确认文件未被篡改。

## 主要功能

| 功能 | 说明 |
|---|---|
| **查指令** | 搜中文就能找到，例如搜「随地安放炸弹」直接出 `mp_plant_c4_anywhere`；支持模糊与拼音式匹配 |
| **问 AI** | 用大白话说需求，AI 结合本地指令库给出方案与可直接粘贴的 cfg |
| **生成配置** | 把选中的指令攒成一份带注释的 `.cfg`，复制或下载 |
| **指令集 / 参数方案** | 多条指令凑成一套、逐条改数值，保存为「编号 + 注释」的方案，随时读取套用；可一键输出**不带注释**、可直接粘进控制台的指令族 |
| **收藏夹** | 多收藏夹管理，支持空夹、参数设置模式、导出 |
| **方案导出 cfg** | 方案可一键导出为 .cfg：按设置直接写进游戏 cfg 目录（导出后控制台 exec 文件名 即生效），或生成到指定位置自己拖进游戏文件夹 |
| **中英对照** | 仅中文 / 仅英文 / 中英对照，三选一 |
| **卡片模式 / 专业模式** | 卡片适合浏览，表格适合批量操作 |

## 安全声明（摘要）

- 本工具是**第三方本地工具**，与 Valve 无关。
- **不修改游戏文件本体**：不注入、不反编译、不替换资源。唯一读取的是游戏自身输出的控制台指令清单（`cvarlist`）。
- **不修改不读取游戏文件本体，不承担任何 VAC 责任。** 任何修改游戏文件本体的行为都可能导致 VAC 封禁。
- 部分指令（标 **cheat**）**只能在本地或自建房使用**，官方匹配服强制 `sv_cheats 0`。
- 你的收藏夹、方案、设置与 AI 翻译缓存**全部保存在本机**，不会上传。

完整条款见软件内「**设置 → 免责声明与安全使用规范**」。

## 隐私

- **不读取、不存储、不上传**任何 Steam 账号或登录凭据。
- AI 接口地址与 API Key 只存在本机浏览器存储中，请求经**本地服务**转发到你填写的接口，不写入任何文件。
- 全部数据可离线使用；不联网也能查指令、管收藏夹、调参数方案。
